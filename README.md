# DED Evidence Portfolio

This folder is ready to publish with GitHub Pages. It contains a public review copy of Ronald Lethcoe's evidence portfolio and the one-page degree completion proposal.

## Publish with GitHub Pages

1. Create a GitHub repository for the portfolio.
2. Upload the **contents** of this folder so `index.html` is at the repository root.
3. In the repository, open **Settings > Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
5. Copy the published Pages URL into the email draft and your personal website.

## Public-copy safeguards

- Original source-file links are removed.
- Email addresses and phone numbers are removed from copied HTML previews.
- The full resume is available privately rather than embedded publicly.
- Video files are held for private faculty review until captioning and rights review are complete.
- The full private evidence archive remains available from Ronald on request.
